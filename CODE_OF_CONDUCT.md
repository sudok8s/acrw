# Code of conduct

ACRW follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep
discussion about the work. Harassment and personal attacks are not tolerated.

Report unacceptable behaviour privately to the maintainer through GitHub
(**Security → Report a vulnerability** works for private contact too) or by
e-mail to the address on the maintainer's GitHub profile. Reports are handled
confidentially.
